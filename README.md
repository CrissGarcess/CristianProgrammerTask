# Summary:
This is a repository for a Unity project created in 48 hours to measure code quality and efficiency by implementing:
- Character movement (Unity Input System)
- Blend tree
- Inventory system
- Save/Load system
- Inventory UI interaction (select items, discard items, change position)

# Branch Guide:

- **main:** Contains the final version of the project with all changes in Unity version 6.2.15.f (Secure Version)

- **Version_6.2.1f:** Contains the final version of the project with all changes in Unity version 6.2.1.f (Security Risk)

- **BuildProject:** Contains the game executable in a ZIP file.

- **Feature branches:** Corresponds to all implemented code divided in features.
